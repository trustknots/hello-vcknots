# Verifier Keys

Place local verifier key material here when running the issuer/verifier server.

Expected default filenames:

- `private_key_openid.pem`
- `certificate_openid.pem`

You can override these paths with environment variables:

- `VERIFIER_PRIVATE_KEY_PATH`
- `VERIFIER_CERTIFICATE_PATH`

This directory ignores key material by default.
